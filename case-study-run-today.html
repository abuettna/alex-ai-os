CASE STUDY · DECISION SUPPORT

“Should I run today?”

One question. Multiple non-identical sources.

Instead of treating one readiness score as the answer, the system combines recovery, recent training, subjective context and the actual calendar before recommending what kind of run fits — or whether running fits at all.

WHAT CHANGES

The same physiology can lead to different advice.

A low recovery marker before an easy day is not the same situation as the same marker before a hard running block, travel or accumulated strength work. Context changes the interpretation.

The output is a decision, not another score.

LIMITS

Decision support, not proof of optimality.

This case demonstrates cross-source contextual reasoning. It does not establish that the recommendation was uniquely correct or caused a better training outcome.
